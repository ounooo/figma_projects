# Bluimpex catalog HTML prototype

Локальный HTML-прототип каталога и кабинета Блюимпекс.

## Запуск

```bash
cd design
python3 -m http.server 8080
```

- Карта экранов: http://localhost:8080/index.html
- Сетка 12 колонок: клавиша `G` или `?grid=1`
